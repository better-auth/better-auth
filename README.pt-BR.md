## Better Auth

Better Auth é um framework de autenticação (e autorização) independente de framework para TypeScript. Ele oferece um conjunto completo de recursos prontos para uso e um ecossistema de plugins que facilita adicionar funcionalidades avançadas com pouco código e em pouco tempo. Se você precisa de 2FA, suporte multi-tenant ou outros recursos mais complexos, o Better Auth deixa você focar em construir a aplicação de verdade — em vez de reinventar a roda.

### Por que Better Auth

Autenticação no ecossistema TypeScript ainda é um problema pela metade. Outras bibliotecas open source costumam exigir bastante código extra para qualquer coisa além do básico. Em vez de empurrar só serviços de terceiros como solução, acredito que a comunidade pode fazer melhor — daí o Better Auth.

## Segurança

Se você descobrir uma vulnerabilidade de segurança no Better Auth, reporte por meio dos [GitHub Security Advisories](https://github.com/better-auth/better-auth/security/advisories/new).

Todos os relatos serão tratados com prioridade, e você receberá o crédito correspondente.
