# Security release on Tuesday, November 3, 2026

We are preparing a security release for Better Auth, scheduled for Tuesday, November 3, 2026.

The related advisories will be published on [GitHub Security Advisories](https://github.com/better-auth/better-auth/security/advisories) at the same time.

## Releases

We will add the release versions here on Tuesday, November 3, 2026.

## How to prepare

* Stay on the current release of your line, so the security release is a small step.
* If you pin Better Auth packages, be ready to lift the pins.
* Watch the [repository's releases on GitHub](https://github.com/better-auth/better-auth/releases) to be notified on Tuesday, November 3, 2026.

## On release day

On Tuesday, November 3, 2026, the new versions go out on npm and the advisories are published on GitHub. We will update this post with the versions and advisory links.

## Contact

If you believe you have found a vulnerability in Better Auth, please read our [security policy](https://github.com/better-auth/better-auth/security/policy) first, then [open a private report on GitHub](https://github.com/better-auth/better-auth/security/advisories/new) or email us at [security@better-auth.com](mailto:security@better-auth.com).
