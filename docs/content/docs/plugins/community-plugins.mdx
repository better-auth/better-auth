title: Community Plugins
description: Community-built plugins that extend Better Auth.
---

Community plugins now live in the [Plugin Marketplace](/marketplace).

Browse curated GitHub repositories, filter by category, and open a plugin to read its README. To list your own plugin, open a pull request against [`docs/lib/marketplace/registry.ts`](https://github.com/better-auth/better-auth/edit/main/docs/lib/marketplace/registry.ts).

To build a plugin from scratch, see [Create your first plugin](/docs/guides/your-first-plugin).
