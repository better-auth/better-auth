title: Community Plugins
description: Community-built plugins that extend Better Auth.
---

Official and community plugins now live in the [Plugin Marketplace](/marketplace).

Browse first-party plugins with quick starts, or curated community packages with README previews. To list your own community plugin, open a pull request against [`docs/lib/marketplace/registry.ts`](https://github.com/better-auth/better-auth/edit/main/docs/lib/marketplace/registry.ts).

<Callout type="warn">
  Community plugins are not official or verified by the Better Auth team. Use them at your own discretion and review their source code before integrating them into your application.
</Callout>

To build a plugin from scratch, see [Create your first plugin](/docs/guides/your-first-plugin).
