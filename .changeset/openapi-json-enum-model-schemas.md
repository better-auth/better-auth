The OpenAPI schema generated by the `openAPI()` plugin now describes `json` fields and enum fields (such as `type: ["free", "pro"]` in `additionalFields`) correctly under `components.schemas`. Before, they were emitted as `"type": "json"` and `"type": ["free", "pro"]`, which are not valid OpenAPI types and broke schema validators and client generators.
